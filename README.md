# Sistem Informasi Kearsipan BPK RI

Pengelolaan arsip aktif di BPK RI masih dilakukan secara konvensional sehingga proses pencatatan, penyimpanan, dan pencarian arsip menjadi kurang efisien serta berisiko menghambat akses informasi. Untuk mengatasi permasalahan tersebut, diperlukan sistem informasi kearsipan yang mampu mendukung pengelolaan arsip secara digital, cepat, aman, dan mudah diakses.

## Fitur Utama

- Manajemen arsip
- Pengelolaan arsip
- Pengelolaan indeks masalah
- Penyimpanan Arsip secara digital

## Teknologi

- **Frontend**: React.Js
- **Backend**: Node.Js
- **Database**: MySQL

## Persyaratan Sistem

- Node.js
- React.js
- MySQL (XAMPP)

## Cara Instalasi

1. **Clone Repository**
   ```bash
   git clone https://github.com/TeeaaRR/PKL.git
   cd PKL
2. **Jalankan MySQL XAMPP**
3. **Masukkan testpkl.sql ke database**
4. **Instalasi Modul Backend**
   ```bash
   cd backend
   npm install
5. **Jalankan Backend**
   ```bash
   nodemon index
6. **Instalasi Modul Frontend**
   ```bash
   cd frontend
   npm install
7. **Jalankan Frontend**
   ```bash
   npm start
